Revit workflow automation

Revit plugins for electrical design and BIM coordination

Built by Raul Kalev, extra-low voltage systems engineer and Revit plugin developer.

RK Tools is a growing library of more than 20 focused tools for reducing repetitive work in Autodesk Revit, spanning design automation, documentation, coordination, analysis, and AI-assisted workflows.

Each tool starts from a practical design problem: make the model easier to understand, keep project data consistent, and give engineers clearer control over recurring tasks. New tools and capabilities are added every month.

CAD visibility and coordination

CAD Manager

CAD Manager is designed for Revit projects that depend on imported or linked DWG references. It brings view-level and layer-level visibility decisions into one focused workflow, helping teams control CAD context without repeatedly navigating standard visibility dialogs.

What it addresses

Large projects can accumulate many CAD files, layers, and view-specific exceptions. CAD Manager focuses on making those decisions easier to review and maintain, including cases where view-template behavior does not provide enough flexibility.

Workflow focus

  • Toggle DWG and layer visibility per view
  • Handle visibility needs beyond normal view templates
  • Retain project settings in a structured data store
Get CAD Manager on Autodesk App Store

Electrical circuit routing

CircuitPath

CircuitPath targets repetitive electrical circuit-path corrections in Revit. Its purpose is to apply a consistent path mode across selected project content while keeping the operation predictable and easy to reverse through Revit's normal undo workflow.

What it addresses

Circuit routing settings can become inconsistent when many devices and circuits are edited over time. CircuitPath provides a focused project-wide action for standardizing the intended path behavior.

Workflow focus

  • Apply the “All Devices” circuit path mode
  • Support repeated runs without stacking unintended changes
  • Keep the operation compatible with normal undo

Security-system coverage

Camera FOV

Camera FOV translates camera sensor and lens information into visual coverage geometry. The goal is to support CCTV planning directly in the Revit model, where designers can review coverage in both plan and three-dimensional context.

What it addresses

Camera placement is easier to evaluate when technical specifications become visible design geometry. The tool focuses on turning field-of-view calculations into model feedback that can be reviewed during coordination.

Workflow focus

  • Calculate viewing cones from sensor specifications
  • Visualize coverage in 2D and 3D
  • Update geometry as parameters change

Design issue coordination

Jira Integration

Jira Integration connects model-review work with issue tracking. It is intended to reduce the context switching involved in documenting a Revit issue, assigning it, and preserving a useful visual reference for the wider project team.

What it addresses

Coordination issues often lose useful model context when they are recreated manually in another system. A direct workflow helps keep issue descriptions, responsibility, and supporting images aligned with the design task.

Workflow focus

  • Create and update Jira issues from the workflow
  • Synchronize priorities and assignees
  • Attach screenshots for clearer design context

Electrical documentation

Panel Schematics

Panel Schematics supports the creation and maintenance of electrical schematic content in Revit. It organizes circuit or panel rows in a structured grid, then uses that information to place detail items and keep electrical parameters aligned with the documented result.

What it addresses

Manual schematic assembly creates repeated placement and data-entry work. The tool focuses on a repeatable flow from organized row data to Revit detail content, reducing inconsistency between the model and the schematic view.

Workflow focus

  • Manage schematic rows in a DataGrid interface
  • Place Revit detail items from structured data
  • Synchronize relevant electrical parameters

Circuit documentation

Single Line Diagrams

Single Line Diagrams explores circuit-driven generation of electrical diagram content. It uses Revit circuit information as the basis for placing diagram elements with consistent level awareness and controllable spacing.

What it addresses

Single-line diagrams are structured but time-consuming to assemble manually. A circuit-led workflow can reduce repeated placement work while maintaining a clearer relationship between model data and documentation.

Workflow focus

  • Generate diagram content from circuit information
  • Account for project levels during placement
  • Apply consistent spacing controls

Lighting coordination

DIALux Import

DIALux Import supports the transfer of lighting-design information into a Revit workflow. It focuses on interpreting linked model content, matching or creating required types, and organizing repeated lighting elements such as LED strips.

What it addresses

Moving lighting-design results into BIM can involve substantial checking and repetitive type management. This workflow aims to reduce manual reconstruction while keeping the resulting Revit elements organized for coordination.

Workflow focus

  • Read relevant lighting content from linked models
  • Create missing Revit types when needed
  • Group LED strip elements intelligently

Model conversion

IFC to Revit

IFC to Revit investigates a controlled approach to converting external model content into native Revit placements. The workflow centers on category and type mapping, batch processing, and predictable placement based on source-object geometry.

What it addresses

Coordination models often contain useful objects that are difficult to reuse directly. A mapping-led conversion workflow can make selected content more practical inside Revit without treating every imported object as the same generic case.

Workflow focus

  • Map source categories and types to Revit content
  • Process multiple placements as a batch
  • Use bounding-box centers for consistent positioning

Cable selection and data

Cable Catalogue

Cable Catalogue provides a structured way to browse and select cable types. It combines rule-based selection with filtering and sorting so designers can narrow a larger catalogue to the options relevant to the current electrical-design task.

What it addresses

Cable data becomes difficult to navigate when naming, materials, and technical properties are spread across a long undifferentiated list. The catalogue workflow makes selection criteria visible and repeatable.

Workflow focus

  • Apply rules to cable-type selection
  • Filter and sort catalogue entries
  • Present the workflow in a focused Material Design interface
AI

AI-assisted Revit workflows

Revit MCP Connector

Revit MCP Connector gives Codex and Claude a controlled connection to a live Autodesk Revit model. Its expanding toolkit supports model queries, electrical design, documentation, coordination, QA, reports, Excel workflows, family creation, and IFC operations without requiring users to write API scripts.

176+ tools More tools and guided workflows are added every month.

What it addresses

AI assistants are most useful when they can work with real project context while model changes remain visible and controlled. The connector combines broad Revit access with approval-aware write actions.

Workflow focus

  • Query model data and generate project QA reports
  • Automate electrical, tagging, sheet, and coordination workflows
  • Use the same connector from Codex and Claude

Model viewing and coordination

Revit IFC Viewer

Revit IFC Viewer places multiple IFC files and the current Revit model in a responsive GPU-accelerated viewport, making large multidisciplinary models easier to navigate, inspect, section, and compare.

What it addresses

Large project models can become uncomfortable to review in a full Revit perspective view. A linked external viewer keeps Revit as the authoring tool while making visual checking faster.

Workflow focus

  • Load and compare multiple IFC models
  • Sync Revit geometry and follow the active selection
  • Inspect properties, sections, opacity, and model differences
PS

Schedule editing and model data

ProSchedules

ProSchedules provides an Excel-like environment for reviewing and editing Revit schedules, combining powerful sorting and filtering with inline edits, auto-fill, grouping, and model highlighting.

What it addresses

Schedule-heavy workflows often require repeated dialog changes and slow cell-by-cell updates. ProSchedules brings those recurring operations into one modeless, persistent workspace.

Workflow focus

  • Filter and sort with multiple prioritized rules
  • Edit, copy, and sequentially fill parameter values
  • Select and focus scheduled elements in Revit
ST

Annotation automation

SmartTags

SmartTags replaces repetitive tag placement with a configurable workflow for direction-aware tag types, anchors, leaders, rotations, batch placement, and automatic collision avoidance.

What it addresses

Dense plan views make consistent annotation difficult. SmartTags measures the resulting tag geometry and searches for a nearby clear position when the intended placement overlaps other content.

Workflow focus

  • Tag selected elements or entire categories in batches
  • Choose tag types based on placement direction
  • Detect collisions and reposition tags automatically
ES

Drawing export and delivery

EliteSheets

EliteSheets lets users search, select, and export any number of Revit sheets to PDF, DWG, and DXF in a single operation without leaving Revit.

What it addresses

Repeating the standard export flow for individual sheets slows down every drawing issue. EliteSheets makes the sheet set the unit of work and reports any failures clearly.

Workflow focus

  • Export PDF, DWG, and DXF together
  • Search and filter large sheet registers
  • Group and merge related DXF outputs
dB

Acoustic design analysis

SoundCalcs

SoundCalcs calculates sound pressure level and Speech Transmission Index from modeled speaker layouts, then renders broadband, octave-band, and intelligibility heatmaps in the active Revit plan.

What it addresses

Speaker layouts are easier to validate when acoustic results are visible in the design environment. The calculation accounts for walls, transmission loss, reflections, reverberation, and directivity.

Workflow focus

  • Calculate SPL and STI across a receiver grid
  • Switch between broadband and octave-band results
  • Render live, range-matched heatmap legends
PV

Views, sheets, and revisions

PlaceViews

PlaceViews is a documentation toolkit for bulk view placement, view and sheet management, parameter editing, duplication, renaming, and revision creation.

What it addresses

Documentation teams repeatedly move between view, sheet, and revision dialogs. PlaceViews keeps those related operations together and gives each batch a clear preview and result summary.

Workflow focus

  • Match and place views across multiple sheets
  • Duplicate, rename, and edit views and sheets in bulk
  • Create and assign project revisions
PU

Project standards and startup

Project Setup

Project Setup provides a central Revit hub for linking external models, creating levels and base views, building plan sets, reviewing warnings, and transferring standards from other open projects.

What it addresses

Early project setup consists of many small but interdependent tasks. A guided hub makes progress visible and reduces the risk of missing a required model or documentation step.

Workflow focus

  • Batch-link IFC and DWG references
  • Create levels, views, sheets, and discipline plan sets
  • Inspect and transfer project standards
CN

Electrical device connection

Connections

Connections creates Revit electrical systems between selected devices and distribution panels, supporting individual or combined circuits with automatic system-type detection.

What it addresses

Connecting many low-voltage or power devices is repetitive and easy to over-provision. The tool checks panel limits and highlights circuits whose reported cable length exceeds the configured threshold.

Workflow focus

  • Connect devices separately or as a shared circuit
  • Enforce optional per-panel circuit limits
  • Highlight and clear cable-length warnings
DA

Lighting controls

DALI Manager

DALI Manager organizes lighting devices under controllers and lines, writes the required assignment parameters, and displays live address and current-capacity gauges.

What it addresses

DALI line planning depends on both address count and current load. Keeping assignments and capacities together makes overloaded lines visible before documentation or commissioning.

Workflow focus

  • Group devices by controller and line
  • Assign the current Revit selection in batches
  • Monitor configured mA and address limits
№

Parameter numbering

Renumber

Renumber writes sequential values to electrical circuits or configurable element parameters as the user picks elements, with dedicated modes for several electrical and extra-low-voltage workflows.

What it addresses

Sequential naming is simple until projects require padding, paired values, prefixes, suffixes, or separate numbering conventions. Renumber keeps those rules visible during the selection session.

Workflow focus

  • Number circuits or arbitrary Revit categories
  • Use ascending, descending, fixed, or paired sequences
  • Adjust the active value from a floating status panel
ID

Project identification standards

RB Type ID

RB Type ID generates structured object identifiers and type numbers from Project Breakdown Structure data, with previews, duplicate checks, assignment history, and non-destructive reconciliation.

What it addresses

Standardized identifiers must stay unique even after copy-paste operations or later changes to an element's level, type, or classification. The plugin maintains a model-side ledger to support audits.

Workflow focus

  • Read discipline and object mappings from PBS Excel data
  • Preview proposed IDs before applying them
  • Repair duplicates and reconcile changed elements
RC

Sheet revision management

Revision Control

Revision Control presents the project's sheets and revisions in a focused modeless interface so users can add or remove a chosen revision across many sheets in one operation.

What it addresses

Updating a drawing issue can involve the same revision change on dozens of sheets. Batch selection makes the intended scope visible and reduces repetitive edits.

Workflow focus

  • Review all sheets and current revision status
  • Apply a revision to selected sheets
  • Remove a revision using the same controlled workflow
FL

Revit content management

Family Library

Family Library indexes reusable Revit family content and presents it as a visual gallery with generated thumbnails, helping users find, load, and place content without leaving Revit.

What it addresses

Folder-based family collections become difficult to scan as they grow. A visual index makes content easier to recognize while preserving the underlying team library structure.

Workflow focus

  • Index configured family-library locations
  • Generate and cache visual thumbnails
  • Load and place selected families in the active project

A practical Revit engineering focus

RK Tools is shaped by extra-low-voltage and electrical-system design work. The goal is not automation for its own sake: each plugin should make a recurring engineering decision clearer, faster, or easier to review inside the project model.
